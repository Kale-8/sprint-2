## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.

## Migración desde Express (Riwi SportsLine) - Setup inicial

Este proyecto se creó para migrar el backend existente en Express a NestJS.

### Configuración de entorno

1. Copia `.env.example` a `.env` y completa las variables:

```bash
cp .env.example .env
```

Variables utilizadas:
- `NODE_ENV`: environment (development | production)
- `PORT`: puerto de la API (por defecto 3000)
- `DATABASE_URI`: cadena de conexión a PostgreSQL (formato: postgres://user:pass@host:port/db)

### Validación y configuración

- Se usa `@nestjs/config` para manejar variables de entorno (global).
- `class-validator`/`class-transformer` están habilitados globalmente mediante `ValidationPipe`.

### Base de datos (TypeORM + PostgreSQL)

- Se sustituyó Sequelize por TypeORM.
- `TypeOrmModule` se configura con `DATABASE_URI` y `autoLoadEntities: true`.
- Entidad migrada: `User` (tabla `usuarios`) con los campos:
  - `id` (PK, autoincremental)
  - `nombre` (string, 100)
  - `email` (string, 150, único)
  - `passwordHash` (string, 255)
  - `rol` (enum: `admin` | `vendedor`)
  - `createdAt`, `updatedAt` (timestamps)

### Ejecutar el proyecto

```bash
npm run start:dev
```

Si la conexión a la BD es correcta, TypeORM sincronizará el esquema (solo en desarrollo).
